# Material 3 visual rules archive

本目錄保存 2026-07-20 以前使用的嚴格 Material Design 3 視覺規則，方便概念方向確認後恢復或逐項校正。

## Archive contents

- `DESIGN_SYSTEM.md`：完整的 Material 3 token、元件、尺寸與無障礙驗收規範。
- `PROJECT_UI_CONSTRAINTS.md`：原本寫在 `PROJECT_CONTEXT_FOR_AI.md` 的 UI 限制。

## Current status

- 這些規則目前不是視覺探索版本的指令來源。
- 下一次 UI 製作應優先讀取專案根目錄的 `UI_EXPLORATION_BRIEF.md`。
- 功能、安全、資料處理、部署與易懂文案規則並未解除。
- `1Campus/` 仍禁止作為視覺或互動參考。

## Restore procedure

方向確認後：

1. 以探索版本為基礎，不直接回退整套視覺。
2. 逐項重新套用可存取性、操作尺寸、焦點、對比與 reduced-motion 規則。
3. 將最終確認的視覺語言整理成新版 `DESIGN_SYSTEM.md`。
4. 更新 `PROJECT_CONTEXT_FOR_AI.md`，將新版 Design System 恢復為 source of truth。
