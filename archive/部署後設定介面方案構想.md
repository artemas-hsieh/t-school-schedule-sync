# 部署後設定介面方案

## 目標

使用者完成 Apps Script 部署與首次授權後，後續調整課表同步設定時，不需要再次進入 Apps Script 編輯器，也不需要修改程式碼。

設定介面應附著在使用者自己的 Google 試算表控制台中，透過自訂選單、對話框或側邊欄操作。所有設定與同步資料均保留在使用者自己的 Google 帳號與 Apps Script 專案中，不需登入開發者網站，也不經過外部伺服器。

## 使用者入口

使用者開啟自己的「課表同步控制台」試算表後，頂端會出現自訂選單，例如：

- 開啟設定
- 立即同步
- 暫停或恢復自動同步
- 查看同步狀態
- 修復同步功能
- 移除受管理的課表事件

主要設定入口為「開啟設定」。

## 設定介面形式

建議使用 Apps Script HTML Service 建立側邊欄或對話框。

- 首次完整設定可使用較大的對話框。
- 後續修改可使用固定在試算表右側的側邊欄。
- 使用者不需要部署額外的 Web App。
- 使用者不需要取得或保存設定網址。
- 使用者不需要執行額外的設定函式。

## 可調整的設定類型

### 課表來源

- 查看目前使用的課表資料來源。
- 更新或重新匯入課表資料。
- 檢查資料是否能正常讀取。
- 顯示目前偵測到的課程與學期資訊。

### 課程選擇

- 選擇哪些課程要同步。
- 全選或取消全選。
- 顯示目前已啟用同步的課程。
- 課表資料更新後，提示新增、移除或變更的課程。

### 目標行事曆

- 顯示目前同步至哪一個 Google Calendar。
- 允許改選既有行事曆。
- 允許建立專門存放課表的行事曆。
- 更換行事曆時提示可能造成的事件搬移或重建。

### 事件顯示方式

- 調整事件標題包含哪些資訊。
- 設定教室、教師、節次或其他資料放置的位置。
- 提供即時事件預覽。
- 避免讓使用者直接修改程式模板或程式碼。

### 提醒設定

- 開啟或關閉提醒。
- 選擇提醒方式與提前時間。
- 套用至所有課程或個別課程。
- 顯示目前使用中的提醒設定。

### 自動同步

- 開啟或關閉自動同步。
- 選擇同步頻率。
- 顯示上次同步時間與結果。
- 提供立即同步按鈕。
- 同步失敗時顯示可理解的錯誤訊息。

## 儲存流程

使用者修改設定後，按下「儲存」或「儲存並同步」。

前端介面透過 `google.script.run` 呼叫 Apps Script 後端函式。後端負責：

1. 驗證設定內容。
2. 將設定寫入 Properties Service 或其他本地設定儲存區。
3. 必要時更新自動同步觸發條件。
4. 必要時重新比對或更新 Calendar 事件。
5. 將執行結果回傳至設定介面。

程式主體不應因使用者設定不同而被修改。所有同步函式每次執行時，都從設定儲存區讀取目前設定。

## 設定變更預覽

對可能大量修改 Calendar 事件的設定，儲存前應先顯示預覽，例如：

- 將新增哪些事件。
- 將更新哪些事件。
- 將移除哪些受管理事件。
- 哪些私人事件不會受到影響。

使用者確認後才正式套用。

## 狀態與錯誤呈現

控制台應清楚顯示：

- 是否已完成設定。
- 自動同步是否啟用。
- 上次同步時間。
- 上次同步是否成功。
- 目前同步的課程數量。
- 需要使用者處理的錯誤或警告。

錯誤訊息應轉換為一般使用者可理解的說明，不應直接只顯示 Apps Script 原始例外訊息。

## 資料與權限原則

- 設定頁執行於使用者自己的 Apps Script 專案。
- 設定儲存在使用者自己的專案或試算表中。
- 不將課表內容、Calendar 資料或設定傳回開發者伺服器。
- 不要求使用者登入額外網站。
- 不要求使用者重新貼上個人化程式碼。
- 不直接修改使用者自行建立、且不屬於本工具管理的 Calendar 事件。

## 程式設計原則

- 固定程式主體與使用者設定分離。
- 所有可調整內容均由設定資料控制。
- 設定資料需有版本欄位，方便日後格式遷移。
- 儲存函式需驗證輸入，不能直接信任前端資料。
- 設定寫入與觸發條件更新應具有錯誤處理。
- 同步事件需有穩定識別方式，避免每次設定變更都刪除全部事件再重建。
- 所有使用者可執行的操作應集中於試算表控制台，不要求進入 Apps Script 編輯器。

## 預期使用流程

1. 使用者打開自己的課表同步控制台。
2. 點選自訂選單中的「開啟設定」。
3. 在側邊欄修改課程、事件格式、提醒或同步設定。
4. 查看變更預覽。
5. 按下儲存。
6. 系統更新設定與必要的觸發條件。
7. 系統執行或排程後續同步。
8. 使用者在控制台查看同步結果。

此方案的核心是：部署完成後，使用者只需要操作試算表中的圖形化控制台，不需要再次接觸程式碼、部署流程或 Apps Script 編輯器。
