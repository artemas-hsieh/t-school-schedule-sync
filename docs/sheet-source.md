# 課程索引與課綱來源

## 兩份索引的用途

- [課程索引](https://docs.google.com/spreadsheets/d/1sEUQ4NuT7CEbxaiXl9pY8nmZaE6iJe7SPYmYbiqDArk/edit)：設定網站公開讀取「高一」「高二」「高三」分頁，必要欄位為「課程名稱」「課程類別」
- [課綱來源索引](https://docs.google.com/spreadsheets/d/1zS6TdGMTPhz2Ja8bRs2AKAg0mRsBfXET9nmXi9wSBjY/edit)：Apps Script 以使用者校內帳號讀取「課綱來源」分頁，再讀取已啟用來源組中的課綱 Sheets

課程類別等於「必修」才預設勾選，其他類別預設不勾選；「預設選取」欄已不再使用，可刪除

網站只取得課程目錄，不讀取受保護課綱，也不推測學期或日期；設定碼以 `sourceKind: course-index` 表示這項邊界，匯入 Docs 時才驗證實際學期與課綱，首次同步前再次讀取

課程名稱必須使用課綱的工作表分頁名稱，不能填分頁內「中文名稱」或自行縮寫；索引已列出但當期課綱沒有的已選課程，匯入時會停止並列出名稱

高一目前可以保持空白；空白列表會顯示尚未提供課程，不會沿用其他年級；日後在既有「高一」分頁補齊列表與課綱來源即可，不需修改程式

## 新增學期

1. 在課綱來源索引新增完整來源組，每份試算表一列
2. 填寫「啟用、來源組鍵、課綱名稱、年級、適用起日、適用迄日、課綱試算表連結」；同組列必須具有相同年級與日期範圍
3. 來源組鍵沿用 `115-1-high2` 形式，前段代表民國學年度與學期；起訖日期必須涵蓋該組所有課程，包括寒暑假課程
4. 使用測試校內帳號確認每份課綱可讀取、每門課都有可辨識的日期與節次後，再啟用完整來源組
5. 更新課程索引中對應年級的課程名稱與類別；更新時間應配合當期結束及下一學期開放選課，避免網站列表與可設定的學期不一致

**保留當前學期來源的啟用狀態，直到該年級課程結束並完成轉換**；停用或刪除當期來源不能證明課程結束

來源啟用後，既有中央索引變更通知會提示相關使用者；加入新課綱本身不會提前暫停本學期同步

學期切換必須同時符合：

- 當前年級、當前學期的全部課程已成功讀取，且最後一堂課已結束；不是只看使用者勾選的課程
- 緊接的下一學期來源組已啟用、課綱可完整解析，並且至少有可驗證的課程時段

不用等待下一學期「適用起日」；滿足條件後沿用 30 分鐘穩定性確認，接著要求確認年級及重新選課，完成前保留既有 Calendar

下學期尚未可讀時仍維持當期；高二下結束可以辨識高三上，但使用者仍須在控制臺確認實際年級

為避免教師刪掉最後幾列就提早切換，程式還會保留曾成功讀取的該學期最晚結束時間；縮短課綱不會把切換時間提前到這個時間之前

此版部署需要更新一次 `Code.gs`；之後只新增正常格式的學期索引與課綱不需要更新程式

## 解析與保護規則

- 使用實際分頁名稱作為課程名稱，忽略名稱以「總表、總覽、目錄、填寫說明、範本、模板」結尾的管理分頁
- 掃描整份分頁定位標頭，支援空白列欄、標頭換行、全半形與常見欄名變體；日期或節次標頭被改名時，只有欄位順序、相鄰標頭與多列資料能唯一定位才補判
- 只依真實合併範圍向下展開儲存格，不把一般空白日期自動當成上一堂課日期
- 日期依來源組適用範圍辨識唯一月日，可處理西元、民國、無年份、數字日期及跨年舊年份；跨年修正保留診斷資訊，不會跨來源組配對
- 支援 `10/7-9` 等明確日期範圍，以及 `234`、`2-4`、`第２～４節`、`1、3、5-6` 等節次格式；不連續節次分開建立，不填補中間缺少的節次
- 第 1–8 節維持固定鐘點；連續跨節含下課及午休，使用第一節開始與最後一節結束
- 純非同步列排除，實體或線上與非同步混合的列保留；日期或節次明確標示「停課、取消、放假、無課程、不上課」時略過
- 教室、主題與內容是可選補充欄位；日期、節次則是建立 Calendar 時段必要的資訊
- 相同時間且內容相同的列去重；衝突列、模糊日期、空白課程分頁、整門課消失、權限或索引讀取失敗時停止該次同步，保留既有行程，不將失敗當成取消或學期結束
- 課程名稱包含節慶等字詞不會因此預設勾選，也不會建立全校活動或課表備註

主同步一次讀取整學期的時段及課程內容，不再只補未來 30 天課綱，也不建立獨立每日課綱更新排程

## 舊版本更新與驗收

1. 暫停原控制臺自動同步，待已開始的工作完成，備份原 `Code.gs`
2. 在原 Apps Script 專案替換新版 `Code.gs`，確認原有 8 項 scopes 與 Sheets v4 進階服務仍存在
3. 保留原 Docs、Script Properties、Calendar 與管理權杖，開啟控制臺檢查選課後手動同步
4. 今天起、由本控制臺建立的非課程事件會列入移除；過去事件、私人事件及其他行事曆不變
5. 原有大量刪除保護仍生效，若清理量超過門檻，使用控制臺的同步預覽檢查後再確認
6. 確認時間、地點、內容與後續調課，再恢復自動同步

本機驗證：`node tests/sheet-source-test.js`、`node tests/smoke-test.js`、JavaScript 語法與 `git diff --check`

仍須用真實 Docs 副本與校內帳號驗收受保護 Sheets、Calendar 寫入、MailApp、OAuth、觸發器及續傳；公開索引讀取和本機 mock 不能代替這些驗收

依使用者發布要求，`index.html` 已恢復設定流程，並與 `configurator.html` 保持一致；網站恢復不代表 Google Docs 母版已更新，母版仍須安裝本次產生的 Code.gs 並完成雲端驗收
