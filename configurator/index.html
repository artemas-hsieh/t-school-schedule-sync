使用步驟

Apps Script 是 Google 提供的線上程式執行工具 → 貼上程式碼 → 依序執行

  1. 1 建立 Apps Script 專案 前往 script.google.com → 點左上角「新專案」→ 刪掉範例文字 → 貼上剛複製的 → 儲存（cmd / ctrl + s）
  2. 2 執行第一次同步 上方函式選單選 syncMyScheduleToCalendar → 按「執行」→ 選擇自己的校內 Google 帳號 → 允許存取試算表與日曆
  3. 3 檢查日曆內容 打開專用 Google 日曆 → 對照原本 Google Sheet → 確認同步正確
  4. 4 建立每日自動同步 函式選單選 setupAutoSyncTriggers → 按「執行」→ 按左側鬧鐘圖示確定觸發條件正確
